# Project overview

**Project lead: Hiran Tiago Lins Borba · Toronto, ON, CA.** [GitHub](https://github.com/htiagolborba).

My goal is to preserve A Link to the Past's gameplay foundation while developing a miniature/diorama 3D presentation with rounded forms, tactile materials, soft lighting and an orthographic camera. The visual direction is inspired by Link's Awakening on Switch; this project does not use Nintendo's engine.

The desktop adaptation builds on snesrev/zelda3, an existing reverse-engineered C reimplementation. My contributions include platform packaging, release tooling, native/presentation experimentation, source-driven art production tools and project documentation, developed with AI assistance. See [credits](CREDITS.md).

Stable public packages retain the original 2D presentation. Current 3D development is private, macOS-first and incomplete. The public repository contains early 3D scaffolding and progress documentation, not the latest private prototype/assets. No new game release accompanies the November 8 documentation checkpoint.

Start with [documentation](docs/README.md), [current status](docs/CURRENT-STATUS.md) or [Claude handoff](docs/AI-HANDOFF.md). The detailed history remains in [CHANGELOG.md](CHANGELOG.md). Game-resource counts are not a measure of finished-game completion.
