## Implemented boundary

This is a C lifecycle probe through Godot's native ABI. The library validates
the engine version and reports init/deinit markers; GDScript verifies the library
is loaded. It does not register a gameplay class or expose the ALttP core to
GDScript. Future native scene bindings and host extraction remain M1 work.

The C header was generated by the pinned engine's
`--headless --dump-gdextension-interface` command. Its original MIT notice is
retained; its hash is recorded in `native/godot_probe/toolchain.json` and checked
by the native build script.

## Scope safeguards

No ROM, extracted maps, original audio, old save data, or stable gameplay source
is touched by this laboratory. Native binaries, engine downloads and caches are
ignored; the original geometry and viewport capture may be versioned.

Stable release automation now ignores 3D-only build scripts and leaves existing
versioned releases intact instead of trying to recreate them. The M0 workflow
uploads diagnostic logs and reports, not a new game release.
