## Zelda ALttP — macOS Intel

A macOS desktop package based on snesrev/zelda3, maintained by Hiran Tiago Lins Borba (Toronto, ON, Canada).

- Intel x86_64 application bundle with a Triforce icon.
- SDL2 linked statically; no Homebrew installation required to play.
- Configuration and saves under `~/Library/Application Support/Zelda ALttP/`.
- Keyboard and SDL2 gamepad input, including OS-compatible Bluetooth/USB controllers.
- Local ROM asset preparation tools, project credits, and component licenses.

Supply your own unmodified USA revision 0 ROM. This download contains no ROM or extracted runtime game assets. Follow the included README before opening the app.

The current presentation is the original 2D game. The diorama visual overhaul is planned, not included. This package is unsigned and not notarized. Apple Silicon native support is not included. Physical controller and gameplay validation remain pending unless recorded in the final release checklist.

Based on snesrev/zelda3; original game and related assets belong to Nintendo. See the included credits and license notices.
