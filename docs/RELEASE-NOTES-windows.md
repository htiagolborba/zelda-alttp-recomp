## Zelda ALttP — Windows x86_64

A Windows desktop package based on snesrev/zelda3, maintained by Hiran Tiago Lins Borba (Toronto, ON, Canada).

- 64-bit Windows executable with a Triforce icon and project version metadata.
- Included SDL2 runtime DLL and `Launch-Windows.cmd` launcher.
- Configuration and saves under `%LOCALAPPDATA%\Zelda ALttP\`.
- Keyboard and SDL2 gamepad input, including OS-compatible Bluetooth/USB controllers.
- Local ROM asset preparation tools, project credits, and component licenses.

Supply your own unmodified USA revision 0 ROM. This download contains no ROM or extracted runtime game assets. Follow the included README and use the launcher rather than opening the EXE directly.

The current presentation is the original 2D game. The diorama visual overhaul is planned, not included. This package is not Authenticode signed. The executable is cross-compiled; full Windows gameplay and physical controller testing remain pending unless recorded in the final release checklist. The CI version check verifies executable loading, not gameplay.

Based on snesrev/zelda3; original game and related assets belong to Nintendo. See the included credits and license notices.
